# 程序设计与问题求解第2次作业
## 第1题

校运动会马上要进行了，现在要进行入场仪式训练：12名女生和24名男生。系统随机产生这36名同学身高（女同学身高在150-180之间，男同学身高在160-190之间）。要求入场时12名女生按身高从低到高排成2行在前面，男生24按同样规则排4行在女生后面；编程输出排好序的身高数据（共6行，每行6个身高数据）（还可以更进一步，就是在每名同学身高后加括号后带上他们原来的编号）程序运行时前2行输出设计者+你的名字，version 1.0。

## 第2题

DNA测序：DNA图谱可以看作一个字符串序列，它由一系列代表着核苷酸顺序的字母组成，如AACGTACAGGT。一个未知DNA序列和数据库中DNA序列的匹配过程实际上是基于两个链之间的一些短链的匹配工作（即短串链重复）。程序运行时前2行输出设计者+你的名字，version 1.0。

任务描述：给定一个长字符串和一个短字符串，找出短串在长串中出现的次数，并输出每次长串中出现短串的起始位置。（可用字符串相关函数简化编程工作）

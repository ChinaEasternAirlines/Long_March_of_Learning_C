# [题号2770] 
## 📝 题目描述

计算两个双精度浮点数a和b的相除的余数，a和b都是正数的。这里余数（r）的定义是：a = k * b + r，其中 k是整数， 0 <= r < b。

输入格式

输入仅一行，包括两个双精度浮点数a和b。

输出格式

输出也仅一行，a÷b的余数。


## 💡 我的思路

先求出整数k:int k = a/b，再用r = a - k*b求出r。

# [题号2773] 
## 📝 题目描述
已知线段的两个端点的坐标A（Xa,Ya），B（Xb，Yb），求线段AB的长度。

输入格式

共两行。
第一行是两个实数Xa，Ya，即A的坐标。
第二行是两个实数Xb，Yb，即B的坐标。
输入中所有实数的绝对值均不超过10000。

输出格式

一个实数，即线段AB的长度，保留到小数点后3位。

## 💡 我的思路

求出A、B两点之间的水平距离(x)和垂直距离(y)

再利用勾股定理开平方根求解[<math.h>下的sqrt()函数]

注意:先比较Xa与Xb,Ya与Yb的大小,再相减,避免出现负数

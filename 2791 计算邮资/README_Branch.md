# [题号2791] 
## 📝 题目描述
根据邮件的重量和用户是否选择加急计算邮费。计算规则：重量在1000克以内(包括1000克), 基本费8元。超过1000克的部分，每500克加收超重费4元，不足500克部分按500克计算；如果用户选择加急，多收5元。


输入格式

输入一行，包含整数和一个字符，以一个空格分开，分别表示重量（单位为克）和是否加急。如果字符是y，说明选择加急；如果字符是n，说明不加急。

输出格式

输出一行，包含一个整数，表示邮费。

样例输入

1200 y

样例输出

17

## 💡 我的思路
输入：读取包裹重量 weight（克）和是否加急的标志 choice（'y' 表示加急）。

基础运费：初始 prize = 8（首重 100 克内 8 元）。

超重计费（重量 > 100 克时）：

计算超出部分 overweight = weight - 100；
每 500 克加收 4 元：(overweight / 500) * 4；
若超出部分不足 500 克（有余数），再补加 4 元（不足 500 克按 500 克算）。
加急费：若 choice == 'y'，额外加 5 元。

输出：打印最终运费 prize。

一句话总结：首重 8 元（100 克内），超重部分每 500 克（不足按 500 克计）加 4 元，加急另加 5 元，最后输出总价。

## 💻 代码实现

```C
#include <stdio.h>

int main(void)
{
    int weight,prize = 8,overweight;
    char choice;
    scanf("%d %c",&weight,&choice);
    if ( weight > 1000)
    {
        overweight = weight - 1000;

        prize = 8 + (overweight / 500) * 4;

        if (overweight % 500)
        {
            prize += 4;
        }
    }
    if (choice == 'y')
    {
        prize += 5;
    }
    printf("%d\n",prize);
    return 0;
}

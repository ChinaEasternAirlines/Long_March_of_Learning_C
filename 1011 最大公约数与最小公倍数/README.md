# [题号1011] 
## 📝 题目描述

输入两个正整数m和n，求其最大公约数和最小公倍数。

输入格式


两个整数

输出格式


最大公约数，最小公倍数

## 💡 原理讲解

1. 最大公约数 —— 辗转相除法（欧几里得算法）

核心定理：gcd(a, b) = gcd(b, a % b)，当 b == 0 时，a 就是最大公约数。

以 m=12, n=18 为例：

步骤	a	b	a % b

初始	12	18	12

1      18	12	6

2	   12	6	0

3	    6	0	停止 → 返回 6

循环中 t = a % b 保存余数，然后 a = b; b = t; 

相当于整体右移一格，直到余数为 0。

示例中余数序列 12 → 6 → 0，最后 a = 6 即最大公约数。


2. 最小公倍数 —— 利用公式

由数论结论：a × b = gcd(a, b) × lcm(a, b)

其中gcd指最大公约数,lcm指最小公倍数

## 💻 代码实现

```C
#include<stdio.h>

int main(void){
    int a,b,t,A,B,num;
    scanf("%d %d",&a,&b);
    A = a;
    B = b;
    while(b!=0){          /*这里是求最大公约数*/
        t = a%b;
        a = b;
        b = t;
    }             /*这里是求最小公倍数*/
    printf("%d %d\n",a,num = A*B/a);
    return 0;    

}
